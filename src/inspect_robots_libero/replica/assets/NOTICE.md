# Source and changes

`meshes/` and `LICENSE` were copied from
`/home/koch/Desktop/kochIRVL/sim/assets/so101/`. That directory supplies the
existing prototype's SO-100/101 arm meshes and bowl mesh under Apache-2.0.
`robot.xml` was derived from `sim/vla_replica_task2_astra_so101_v1.xml`:
the task objects and keyframes were removed, mesh paths were made local, and
task bodies/keyframes are now generated by `replica/scenes.py`.

`../controller.py` adapts `kochIRVL/sim/controller.py`: task-specific bowl
scoring and the multi-tick move helper were removed; rendering uses a smaller
compass. `replica/embodiment.py` applies one physical control tick per framework
action and `replica/scoring.py` owns new private task predicates.

The external repository is not imported at runtime and remains read-only.
Reference photographs and the VLA Replica paper are not redistributed here.
Generated layouts are approximate manual configurations, not recovered camera
calibrations or measured object placements. Cloth, wiping, and pepper have
explicit proxy implementations; see `REPLICA.md`.
